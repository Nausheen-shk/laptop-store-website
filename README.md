# 💻 LaptopStore - Premium E-Commerce Website

A modern, premium, fully responsive laptop e-commerce website built with HTML5, CSS3, Bootstrap 5 & Vanilla JavaScript. Inspired by Apple & Linear UI.

🔗 **Live Demo:** https://nausheen-shk.github.io/laptop-store-website/

### ✨ Features
- **Premium Dark UI** - Modern gradient, glassmorphism & animations
- **Smart Filtering** - Filter by brands (HP, Dell, Apple, Lenovo, ASUS)
- **Real-time Search** - Search laptops instantly
- **Product Detail Modal** - Click on any laptop to view full specs, description & images
- **Shopping Cart** - Add to cart, remove, quantity management & dynamic total
- **Fully Responsive** - Works perfectly on mobile, tablet & desktop
- **Deployed on GitHub Pages**

### 🛠️ Tech Stack
- HTML5, CSS3
- Bootstrap 5.3
- JavaScript (ES6)
- Google Fonts (Space Grotesk + Inter)
